# 社会保険労務士川村事務所 ランディングページ

盛岡市の社会保険労務士事務所「社会保険労務士川村事務所」の 1 ページ構成のコーポレートサイト（LP）です。
ビルドツールを使わない静的サイトで、HTML / CSS / JavaScript（Vanilla）のみで構成しています。

公開 URL: https://morioka-shougai.jp/

## ページのセクション

| ID | セクション | 内容 |
| --- | --- | --- |
| `#hero` | ファーストビュー | キャッチコピーと問い合わせ CTA |
| `#about` | 事務所について | 代表者プロフィール・事務所紹介 |
| `#service` | 対応業務 | 労務相談／就業規則／給与計算／障害年金 |
| `#flow` | ご相談の流れ | STEP 1〜4 |
| `#contact` | お問い合わせ | 電話番号・所在地・対応エリア |

## 動作環境・開発

依存パッケージやビルド手順はありません。ファイルを直接編集し、ブラウザで `index.html` を開けば確認できます。

ローカルサーバーで確認する場合（フォントの読み込みなどが本番に近くなります）:

デプロイは `index.html` / `css` / `js` / `images` をそのままサーバーへアップロードするだけです。

## 編集時の注意点

- **電話番号は 4 箇所に直書き**されています（ヘッダー・ヒーロー下 CTA・お問い合わせ・スマホ固定 CTA）。変更時は `index.html` 内の `090-4739-1620` をすべて置換してください。JSON-LD 内の `telephone` も対象です。
- **お問い合わせフォームは現在 HTML 上に存在しません。** ボタンは外部の `https://morioka-shougai.jp/contact/` へリンクしています。[js/main.js:154-285](js/main.js#L154-L285) のフォーム処理は `#inquiry-form` を持つマークアップを追加したときに有効になります。その際は先頭の `FORM_ENDPOINT`（[js/main.js:15](js/main.js#L15)）に送信先 URL を設定し、エラーメッセージ内のダミー番号 `019-XXXX-XXXX` を実際の番号へ差し替えてください。
